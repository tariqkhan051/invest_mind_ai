# AI Investment Manager
# Portfolio Engine

Version: 1.0

Status: MVP

---

# 1. Purpose

The Portfolio Engine is the core business module of the AI Investment Manager.

It is responsible for maintaining the user's investment portfolio, tracking performance, calculating returns, managing cash flow, and providing portfolio insights to the AI Decision Engine.

Every recommendation generated by the system depends on the Portfolio Engine.

---

# 2. Responsibilities

The Portfolio Engine shall:

- Manage investment accounts
- Maintain portfolio holdings
- Record all transactions
- Calculate portfolio value
- Calculate gains and losses
- Calculate XIRR
- Calculate CAGR
- Calculate allocation percentages
- Track cash balance
- Generate portfolio snapshots
- Provide portfolio metrics to other modules

---

# 3. Supported Assets (MVP)

The Portfolio Engine supports:

- Mutual Funds

- Cash

Future versions may include:

# 6. Holdings

A holding represents the current ownership of an investment.

Fields

- Asset
- Quantity / Units
- Average Cost
- Current NAV / Price
- Market Value
- Unrealized Gain
- Allocation %

Holdings are calculated automatically from transactions.

---

# 7. Transactions

Supported transaction types

- Buy
- Sell
- Switch In
- Switch Out
- Dividend
- Bonus Units
- Fee
- Adjustment

Every portfolio change must originate from a transaction.

Holdings must never be edited directly.

---

# 17. Business Rules

- Portfolio value is calculated using the latest market data.
- Holdings are derived from transactions.
- Transactions are immutable.
- Negative holdings are not allowed.
- Cash balance cannot become negative unless margin is explicitly enabled.
- Deleted transactions are not permitted; use reversal transactions instead.
